#  Student Management System

A full-stack MERN application for managing student records, course enrollments, and user roles. Features continuous deployment, JWT authentication, and a responsive Tailwind CSS interface.

---

##  Tech Stack

* **Frontend:** React (Vite), Tailwind CSS, Axios, Lucide Icons
* **Backend:** Node.js, Express.js, JWT (JSON Web Tokens)
* **Database:** MongoDB (via Mongoose)
* **Deployment:** Vercel (Unified Serverless Setup)

---

##  Features

*  **Authentication & Authorization:** Secure JWT login/signup with Role-Based Access Control (RBAC).
*  **Interactive Dashboard:** Dynamic views for managing students and tracking key metrics.
*  **CRUD Operations:** Create, read, update, and delete student entries seamlessly.
*  **Modern UI:** Built with Vite and Tailwind CSS for rapid loading and smooth performance.
